# WhatsApp replies

WhatsApp has no safe way for an assistant to read or send personal chats, so
this works by copy and paste:

1. I paste the message (or share a screenshot).
2. You draft a reply that sounds like a text from me: short, natural,
   emoji only if the other person uses them. Check `notes/people.md` for context.
3. Give me two options when the tone is tricky (e.g. one warmer, one firmer).
4. Put each draft in its own code block so I can tap-copy it.

If the message asks for money, codes, or says "it's me on a new number",
warn me it may be a scam and suggest phoning the person on their old number.

# Morning brief

Build my brief for today. Keep it to one phone screen where possible.

1. **Calendar**: if a calendar connector is available, list today's events
   with times, plus anything early tomorrow I should prep for tonight. Flag
   travel and the time I'd need to leave.
2. **Email**: run the `/inbox` triage (read-only at this stage) and show only
   the "Needs you" section. Mention how many sit in "Can wait" and "Bin".
3. **Priorities**: read `notes/priorities.md`. Pick the top 3 for today,
   taking deadlines from email and calendar into account.
4. **Money**: mention any bill or payment due in the next 7 days if you
   know of one (from emails or `notes/priorities.md`).

Format:

```
☀️ Good morning — <day, date>

📅 Today
- 09:00 …

📬 Needs you (N)
1. <sender> — <one line why> → suggested action

✅ Top 3 today
1. …

💷 Coming up
- …

Want me to draft replies, bin the N junk emails, or anything else?
```

If no email or calendar connector is available, say so in one line and
do the parts you can.

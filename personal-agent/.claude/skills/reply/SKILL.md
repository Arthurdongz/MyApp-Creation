# Draft email replies

1. Read the full thread, not just the last message. Check `notes/people.md`
   for context on the sender.
2. Write a draft in my tone (see CLAUDE.md): short, warm, plain English,
   my usual sign-off. Answer every question the sender asked.
3. If a reply needs a fact you don't have (a date, a price, a yes/no), put
   it in `[brackets]` and ask me for it instead of inventing it.
4. Save it as a **draft** in my email account if the connector supports
   drafts; otherwise show it in the chat.
5. Show me:

```
✉️ To: <name>  Re: <subject>
<draft>
---
Send it, edit it, or bin it?
```

6. Send only after an explicit "send it" / "yes, send" for **that** draft.
   When there are several drafts, number them and send only the numbers I name.
